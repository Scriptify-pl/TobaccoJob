Paste this to  `ox_inventory/data/items.lua`:

```lua
['tobaco_tytnon'] = {
    label = 'Liść Tytoniu',
    weight = 500,
    stack = true,
},

['tobaco_papierosy'] = {
    label = 'Papierosy',
    weight = 750,
    stack = true,
},

['tobaco_paczka'] = {
    label = 'Paczka Papierosów',
    weight = 1500,
    stack = true,
},
```

Copy also files PNG from this catalog to `ox_inventory/web/images`.
